# Fairy V3 Resources

This directory contains only product assets approved by the legacy intake.
Every binary or text asset must have an entry in `manifest.json` before it is
used by a build, runtime, or test.

Manifest entries record the source path, SHA-256 digest, provenance assertion,
intended use, destination path, and validation status. Model weights, caches,
generated speech, and unreviewed legacy media are not committed here.
